# O POVO - Movie App 🎬

Este é um projeto desenvolvido como parte do teste prático para Desenvolvedor Mobile no O POVO. O aplicativo permite visualizar filmes populares, ver detalhes e gerenciar uma lista de favoritos com persistência em nuvem.

## 🚀 Tecnologias Utilizadas
- **React Native** com **Expo** (EAS Build)
- **Firebase Auth** (Autenticação)
- **Cloud Firestore** (Persistência de favoritos em tempo real)
- **Styled Components** (Estilização e Temas)
- **Axios** & **TMDB API** (Consumo de dados)
- **Lucide React Native** (Ícones)
